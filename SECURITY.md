# Security

Pixie Privacy Pro runs locally: it talks to the EMEET PIXY over USB, reads Windows' camera and microphone usage records,
and installs a virtual camera and a LocalSystem service that disables only the PIXY recording device. It does not use the network.

## Reporting a vulnerability

Please report security problems privately through
[GitHub private vulnerability reporting](https://github.com/Gamchikot/PixiePrivacyPro/security/advisories/new),
not in public issues. Describe the version, Windows build and steps to reproduce. You should get an answer within a week.

Only the latest release gets fixes.

## Безопасность

Об уязвимостях сообщайте закрыто через
[GitHub private vulnerability reporting](https://github.com/Gamchikot/PixiePrivacyPro/security/advisories/new),
а не в открытых issues. Укажите версию, сборку Windows и шаги для повторения. Исправления выходят только для последнего релиза.
